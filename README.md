# Plato

English and Greek texts of Plato displayed side by side by Stephanus section.

Read the site at [cb341.dev/plato](https://cb341.dev/plato).

## Build

The static HTML pages are generated from the TEI XML files in `src/`:

```sh
python3 build.py
```

The site is published through GitHub Pages.

## Sources and license
